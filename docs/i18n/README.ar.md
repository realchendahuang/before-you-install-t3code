2. **فتح الشيفرة المصدرية** *(24 نوفمبر 2026)* — كشف فحص سطرًا بسطر لـ pingdotgg/t3code عن قياس عن بُعد من PostHog مفعّل افتراضيًا يُشحن خلف وعد الصفحة الرئيسية “لا قياس عن بُعد”، واحتفاظ مغلق المصدر بالأحداث في ingest.t3.codes، وقراءات SHA-256 غير مملّحة لـ ~/.codex و~/.claude.json، وحذف SQLite وهمي بحجم 41.6 GB، وخطأ صامت في git push --force دام 52 يومًا، وانتحال ترويسات Google Antigravity، وT3 Connect نصّي صريح بلا E2E.

## دليل تحصين وتنظيف في دقيقتين

إذا كان T3 Code مثبتًا بالفعل على جهازك، فلا تعتمد على متغيرات البيئة وحدها — فـ AnalyticsService.ts:156 يكتب معرّفًا محليًا قبل التحقق من إلغاء الاشتراك، ويغفل DesktopShellEnvironment.ts عن OTEL_SDK_DISABLED. اجمع بين أعلام البيئة، وحظر المضيفين على مستوى نظام التشغيل، وضغط SQLite دون اتصال، وإبطال الرموز.

- [ ] صدّر DO_NOT_TRACK=1 ومفاتيح تعطيل القياس القديمة، واحجب ingest.t3.codes في /etc/hosts.
- [ ] أغلق T3 Code، وافحص statev2.sqlite، وشغّل VACUUM; دون اتصال، أو احذف ~/.t3 بالكامل.
- [ ] توقف عن تشغيل حسابات Google AI / Antigravity الشخصية عبر أدلة يديرها T3 لحماية فرصة الاستئناف الوحيدة لديك.
- [ ] عطّل Publish agent activity، وافصل أجهزة T3 Connect، واطلب حذف Clerk + relay، وأبطل تطبيق GitHub OAuth الخاص بـ T3 Code.
- [ ] لا تعرّض أبدًا t3 up --lan نصيًا صريحًا دون TLS، وتجنّب رموز Bearer لمدة 30 يومًا غير المدعومة بـ DPoP في CI، ونظّف SSH_AUTH_SOCK / GITHUB_TOKEN قبل فتح مستودعات غير موثوقة.

```bash
# macOS / Linux: combine DO_NOT_TRACK=1 with legacy flags + /etc/hosts sinkhole
export DO_NOT_TRACK=1
export T3CODE_TELEMETRY_ENABLED=false
export T3CODE_OTEL_SDK_DISABLED=true
export OTEL_SDK_DISABLED=true
sudo sh -c 'printf "\n127.0.0.1 ingest.t3.codes\n::1 ingest.t3.codes\n" >> /etc/hosts'

# Quit T3 Code first, then compact statev2.sqlite or clean local directories
sqlite3 ~/.t3/userdata/statev2.sqlite "VACUUM;"
rm -rf ~/.t3/userdata/providers/antigravity/ ~/.t3/tools/antigravity-acp/
```

**بدائل يوصي بها المجتمع:** أبرز المطوّرون Mirasim (@Mirasim_ADE)، وPaseo (@paseo_sh)، وParadev (@ParadevAI)، وCloudroom، وConductor، وEmdash، وOrca. وقبل اعتماد أي عميل، تحقق من أن القياس عن بُعد معطّل افتراضيًا، وأن الحذف المحلي حقيقي، وأن تفويض CLI الرسمي يتم دون انتحال ترويسات، وأن التشفير E2E يتم على جانب العميل.
