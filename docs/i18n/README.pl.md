## Dwuminutowy plan zabezpieczenia i czyszczenia

Jeśli T3 Code jest już zainstalowany na Twoim komputerze, nie polegaj wyłącznie na zmiennych środowiskowych — AnalyticsService.ts:156 zapisuje lokalny identyfikator przed sprawdzeniem rezygnacji, a DesktopShellEnvironment.ts pomija OTEL_SDK_DISABLED. Połącz flagi środowiskowe, blokowanie hostów w systemie, kompakcję SQLite w trybie offline i unieważnianie tokenów.

- [ ] Ustaw DO_NOT_TRACK=1 i starsze przełączniki wyłączające telemetrię, a następnie przekieruj ingest.t3.codes do adresu blokującego w /etc/hosts.
- [ ] Zamknij T3 Code, przejrzyj statev2.sqlite, uruchom VACUUM; w trybie offline albo całkowicie usuń ~/.t3.
- [ ] Przestań uruchamiać osobiste konta Google AI / Antigravity przez katalogi zarządzane przez T3, aby chronić swoją jedyną możliwość odwołania.
- [ ] Wyłącz publikowanie aktywności agenta, odłącz komputery T3 Connect, poproś o usunięcie danych Clerk + relay i unieważnij aplikację OAuth T3 Code w GitHubie.
- [ ] Nigdy nie wystawiaj działającego jawnym tekstem t3 up --lan bez TLS, unikaj 30-dniowych tokenów Bearer bez DPoP w CI i oczyść SSH_AUTH_SOCK / GITHUB_TOKEN przed otwarciem niezaufanych repozytoriów.

```bash
# macOS / Linux: combine DO_NOT_TRACK=1 with legacy flags + /etc/hosts sinkhole
export DO_NOT_TRACK=1
export T3CODE_TELEMETRY_ENABLED=false
export T3CODE_OTEL_SDK_DISABLED=true
export OTEL_SDK_DISABLED=true
sudo sh -c 'printf "\n127.0.0.1 ingest.t3.codes\n::1 ingest.t3.codes\n" >> /etc/hosts'

# Quit T3 Code first, then compact statev2.sqlite or clean local directories
sqlite3 ~/.t3/userdata/statev2.sqlite "VACUUM;"
rm -rf ~/.t3/userdata/providers/antigravity/ ~/.t3/tools/antigravity-acp/
```

**Alternatywy polecane przez społeczność:** Deweloperzy wskazywali Mirasim (@Mirasim_ADE), Paseo (@paseo_sh), Paradev (@ParadevAI), Cloudroom, Conductor, Emdash i Orca. Przed wyborem dowolnego klienta sprawdź, czy telemetria jest domyślnie wyłączona, czy dane są rzeczywiście usuwane lokalnie, czy oficjalne CLI jest wywoływane bez podszywania się pod nagłówki oraz czy szyfrowanie end-to-end odbywa się po stronie klienta.
