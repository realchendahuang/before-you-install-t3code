# #08 · Buku Besar Bisnis Senilai $800 Ribu+ & Radar Komputasi Harian 31,7 Triliun Token

> Telemetri yang aktif secara default bukanlah kelalaian teknis: ia membiayai radar intelijen real-time berkapasitas 31,7 triliun token/hari (setara pengeluaran API $10,19 juta/hari) yang ditukar dengan token early-access OpenAI gratis senilai $300 ribu+ dan pendekatan kepada investor.

<!-- section:claim -->
## Apa yang Diklaim

- T3 Code dibingkai sebagai alat open-source MIT gratis yang murni digerakkan passion, dan telemetri hanya dibela sebagai penghitungan dasar untuk *"know how many users we have."*
- `@theo` juga mengklaim bahwa `@PatrickToulme` dari DeepMind telah menyumbang *"many PRs"* ke T3 Code.

<!-- section:evidence -->
## Apa yang Ditunjukkan Bukti

- **Pengeluaran $800 ribu+ & peralihan total dari produk berbayar:** Dari seluruh **1.151 unggahan X berturut-turut** pada 7–24 November, `@theo` menyebut T3 Code sebanyak **162 kali (14,1%)** dibandingkan **0 penyebutan** untuk produk berbayar warisannya (`T3 Chat`, `UploadThing`, `ping.gg`), sekaligus mengonfirmasi secara publik pengeluaran dari kantong sendiri sebesar **$800 ribu+** untuk klien gratis tersebut ([`2120729779511124267`](https://x.com/theo/status/2120729779511124267)).
- **Radar analitik 31,7 triliun token/hari ($10,19 juta/hari):** Event mentah yang disimpan melalui `ingest.t3.codes` yang bersumber tertutup menggerakkan dasbor internal yang melacak **31,7 triliun token/hari** (setara pengeluaran API **$10,19 juta/hari** pada 18 November, memuncak mendekati **$10,2 juta/hari**) serta rincian pembagian pangsa lab yang sangat halus (`99%` ditopang langganan, `~98,5%` pada Codex/Claude/Antigravity, pangsa open-weight turun dari `15%` ke `6%`). Ketika seorang komentator berspekulasi soal pangsa pasar pada 23 November, `@theo` mengejeknya karena tidak memiliki akses ke analitiknya ([`2124682906132181482`](https://x.com/theo/status/2124682906132181482)).
- **Mengubah telemetri pengguna menjadi fasilitas lab & daya tawar VC:** `@theo` secara publik menyebut telah menghabiskan **$300 ribu+ token early-access OpenAI gratis tanpa batas** untuk benchmark GPT-6.2 Astra ([`2122760447103484410`](https://x.com/theo/status/2122760447103484410)), menjalankan benchmark bare-metal Google, dan menerima pendekatan investor (*"multiple investors have asked me about this"*, [`2123885732330885417`](https://x.com/theo/status/2123885732330885417)).
- **Kolaborasi lab yang dibesar-besarkan:** Riwayat commit Git yang difilter dengan `patrick-toulme` menunjukkan tepat **1 commit** ([`PR #31158`](https://github.com/pingdotgg/t3code/pull/31158)), bukan *"many PRs."*
