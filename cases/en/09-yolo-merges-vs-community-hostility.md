# #09 · Internal `yolo merges` vs. External Community Hostility & `.github/VOUCHED.td` Bans

> Internally, T3 Code shipped 500 commits/day through automated agent loops and admitted "yolo merges breaking shit" — while externally telling contributors "here's my advice: Don't", denouncing users via `.github/VOUCHED.td`, and insulting issue reporters.

<!-- section:claim -->
## What Was Claimed

- T3 Code markets itself as a fast-moving, community-embracing open-source project built by engineers for engineers.

<!-- section:evidence -->
## What the Evidence Shows

- **Reckless internal merge velocity:** `@theo` publicly described shipping **500 commits/day** ([`2120741101250515322`](https://x.com/theo/status/2120741101250515322)), running **700 concurrent agents**, batch-merging community PRs through an automated agent loop, admitting *"my yolo merges breaking shit sometimes"* ([`2119951615679672513`](https://x.com/theo/status/2119951615679672513)), and joking that risking a machine wipe equals *"free content"* ([`2119993037971730879`](https://x.com/theo/status/2119993037971730879)).
- **Hostile governance & public denouncement bans:** [`CONTRIBUTING.md`](https://github.com/pingdotgg/t3code/blob/main/CONTRIBUTING.md) opened with *"here's my advice: Don't"*, backed by [`.github/VOUCHED.td`](https://github.com/pingdotgg/t3code/blob/main/.github/VOUCHED.td) denouncement auto-bans and **174 `unwanted` labels** across rejected community PRs.
- **Unilateral feature removals & user insults:** [`PR #5551`](https://github.com/pingdotgg/t3code/pull/5551) buried the Build/Plan toggle (*"Reality check for those upset"*, 10 downvotes), [`PR #9190`](https://github.com/pingdotgg/t3code/pull/9190) hid the context usage ring (16 downvotes, repository high), and [`PR #33131`](https://github.com/pingdotgg/t3code/pull/33131) deleted Plan mode outright with a self-contradictory AI summary. In [`Issue #33639`](https://github.com/pingdotgg/t3code/issues/33639#issuecomment-6765462545), `@theo` told user `@bermudi` to *"uninstall our software"* and called him an *"ungrateful prick"* — rejecting his follow-up [`PR #41572`](https://github.com/pingdotgg/t3code/pull/41572) the next morning.
- **Follower gatekeeping on X:** Contributors were scolded for not following `@theo` ([`2120821423438778667`](https://x.com/theo/status/2120821423438778667)), threatened with removing `/btw` ([`2120853340078874923`](https://x.com/theo/status/2120853340078874923)), and told an annotated screenshot beats submitting a PR ([`2123754193530053110`](https://x.com/theo/status/2123754193530053110)).
