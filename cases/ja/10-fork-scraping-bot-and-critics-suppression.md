# #10 · 公開 `@bot` によるフォークの無断取得、競合への嘲笑、批評家の抑圧

> 競合他社がUIパターンを模倣していると嘲笑する一方で、`@theo` は開発者のフォークに公開返信で「Okay I'm stealing this」と述べ、30秒後に `@bot` を送り込んで彼女のコードを無断取得した。さらに自動ブロッカーを導入し、フォロワーに批評家の収益化を停止させるよう促していた。

<!-- section:claim -->
## 何が主張されていたか

- 11月24日、`@theo` は Claude Code Desktop がサイドバータブを追加したことを公然と嘲笑し（[`2124987957803446311`](https://x.com/theo/status/2124987957803446311)）、模倣品に対して独自の製品開発を守っていると自らを描いた。

<!-- section:evidence -->
## 証拠が示すもの

- **30秒での公開 `@bot` フォーク取得（`2119240810202034645`）：** 11月8日、独立開発者 `@MiaAI_lab` が自作のカスタムフォーク機能を共有した後、`@theo` は「Okay I'm stealing this」と返信し、その30秒後にリプライ欄で自身の自動化ボット（`@bot`）を公然とタグ付けして、Opus 5.5 を使って彼女のフォークを特定し `beebox` に取り込ませた。
- **要求に応じた競合機能のクローン（`2121017649652269120`）：** 11月13日、ユーザーが競合ツールの機能を称賛した際、`@theo` は再び公開リプライで `@bot` を送り込み、その機能を T3 Code に直接クローンさせた。
- **批評家の収益化停止と自動一括ブロック：** X上の批評家に対して、`@theo` はフォロワーに「demonetize them」することだけを目的にコミュニティノートを提出するよう促し（[`2120238923884696025`](https://x.com/theo/status/2120238923884696025)）、11月24日だけで約100アカウントをブロックした自動Xブロッカーボットを運用していることを公然と認めた（[`2125077510941802509`](https://x.com/theo/status/2125077510941802509)）。

<!-- section:status -->
## 上流のステータス（`ca81b7b9`）

- **公開記録：** 公開された `@bot` の取得リプライ、コミュニティノートに関する発言、自動ブロッカーの確認はすべて、アーカイブ内に記録されたまま残っている。
