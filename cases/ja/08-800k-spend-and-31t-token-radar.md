# #08 · 80万ドル超のビジネス台帳と1日31.7兆トークンの計算資源レーダー

> デフォルト有効のテレメトリはエンジニアリング上の見落としではなかった。それは、無料の OpenAI アーリーアクセストークン30万ドル超と投資家への働きかけと引き換えに運用されていた、1日31.7兆トークン（1日あたり1,019万ドル相当の API 支出）のリアルタイム情報レーダーを支えていた。

<!-- section:claim -->
## 何が主張されたか

- T3 Code は純粋な情熱による無料の MIT オープンソースツールとして位置づけられ、テレメトリは *"know how many users we have."* のための単純なカウントにすぎないと弁明された。
- `@theo` はさらに、DeepMind の `@PatrickToulme` が T3 Code に *"many PRs"* を投じたと主張した。

<!-- section:evidence -->
## 証拠が示すもの

- **80万ドル超の支出と有料製品からの完全な転換:** 11月7日から24日までの連続する X 投稿 **1,151件** すべてを通じて、`@theo` が T3 Code に言及したのは **162回（14.1%）**。これに対し、旧来の有料製品（`T3 Chat`、`UploadThing`、`ping.gg`）への言及は **0回** だった。一方で同氏は、無料クライアントに **80万ドル超** を自腹で投じたことを公に認めている（[`2120729779511124267`](https://x.com/theo/status/2120729779511124267)）。
- **1日31.7兆トークン（1日1,019万ドル）の分析レーダー:** クローズドソースの `ingest.t3.codes` を通じて保持された生イベントが、**1日31.7兆トークン**（11月18日時点で **1日1,019万ドル** 相当の API 支出、ピークは **1日約1,020万ドル**）を追跡する社内ダッシュボードを支えていた。さらにラボ別シェアの細かい内訳（`99%` がサブスクリプション経由、Codex/Claude/Antigravity 全体で `~98.5%`、オープンウェイトのシェアは `15%` から `6%` へ低下）も把握していた。11月23日、あるコメンテーターが市場シェアについて推測すると、`@theo` は自身の分析データにアクセスできないことを嘲笑した（[`2124682906132181482`](https://x.com/theo/status/2124682906132181482)）。
- **ユーザーテレメトリをラボの特典と VC 交渉力へ変換:** `@theo` は、GPT-6.2 Astra のベンチマークで、無制限に使える無料の OpenAI アーリーアクセストークンを **30万ドル超** 分消費したと公言し（[`2122760447103484410`](https://x.com/theo/status/2122760447103484410)）、Google のベアメタルベンチマークを実行し、投資家からの接触にも対応していた（*"multiple investors have asked me about this"*、[`2123885732330885417`](https://x.com/theo/status/2123885732330885417)）。
- **誇張されたラボとの協働:** `patrick-toulme` で絞り込んだ Git コミット履歴が示すのはちょうど **1件** のコミット（[`PR #31158`](https://github.com/pingdotgg/t3code/pull/31158)）であり、*"many PRs"* ではない。

<!-- section:status -->
## 上流の状況（`ca81b7b9`）

- **公開記録／現行のビジネスモデル:** `ingest.t3.codes` は `ca81b7b9` 時点でもクローズドソースかつデフォルト有効のままで、同じファーストパーティの分析パイプラインへ供給を続けている。
