# #00 · 起因导火索：“偷我们的代码”、Fork 封号威胁与赤裸双标

> 11 分钟内，@theo 连发两帖将一名中国开发者的免费 MIT 二改辱骂为「Chinese knockoff」「Temu3 Code」并威胁找 GitHub 封掉其账号；不到 11 小时后，他又公开表态欢迎万亿美元美国大厂照抄 MIT 代码。

<!-- section:claim -->
## 官方 / Theo 宣称

- T3 Code 官网（[`t3.codes`](https://t3.codes/)）将自己的开源 GitHub 仓库入口直接标作 *"Steal our code (legally)"*（合法偷走我们的代码），并采用宽松的 MIT 协议开源。
- 攻击中国开发者不到 11 小时后，面对网友提问“如果万亿美元美国大厂照抄 T3 Code 会不会介意”，`@theo` 公开回复：*"Nah. Open source is open source, even if a trillion dollar company uses it!"*（开源就是开源，哪怕万亿美元公司拿去用也无所谓，[`2124989435154726982`](https://x.com/theo/status/2124989435154726982)）。

<!-- section:evidence -->
## 源码与公开记录铁证

- **针对中国开发者的辱骂与封号威胁（2026-11-23 19:11–19:54 CST）：** 有路人将中国开发者 `@DDdxx666` 基于 MIT 协议制作的免费二改误当成官方客户端。`@theo` 在 11 分钟内连发两帖将其定性为 *"Chinese knockoff"* 与 *"Temu3 Code"*，并公开威胁要找 GitHub 封掉对方整个账号：*"Do it right now or I'm going to contact GitHub and have your account taken down"*（[`2124829315657576890`](https://x.com/theo/status/2124829315657576890)）。
- **30 分钟光速改名 vs 不对等私信道歉：** `@DDdxx666` 在 30 分钟内就将项目更名为 `Stardust` 并移除了全部 T3 标识。`@theo` 仅在私信里道了歉，却让两条合计超过 20 万曝光的公开辱骂帖继续挂在主页上。
- **赤裸的国籍选择性执法：** T3 团队员工 `@maria_rcks` 自己就公开托管着名为 `maria-rcks/t3libre`（*"T3 Code, liberated"*）的二改仓库；GitHub 上英文命名的 `t3code-quota-ui`、`t3code-atlas`、`t3code-bar` 等项目也全部安然无恙，从未收到任何封号威胁。
- **自家 FAQ 白纸黑字承认借鉴他家：** T3 Code 官方 FAQ 明确写明自身设计直接借鉴了 Codex Desktop、Conductor、Claude Desktop 与 Cursor（[`2125066677188702698`](https://x.com/realchendahuang/status/2125066677188702698)）。
- **引爆全球源码大起底：** 从 11 月 24 日起，针对 `pingdotgg/t3code` 源码、提交记录与公开档案的逐行核查陆续查出后续全部 19 项实锤，直接触发欧盟 GDPR 正式举报与近 20 个通宵急救补丁。
