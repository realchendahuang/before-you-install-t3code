# #08 · 自掏 80 万美元的真实账本：日跑 31.7 万亿 Token（$10.19M/天）算力雷达

> 默认开启的遥测绝非“顺手统计人数”：它为 @theo 撑起了一台日跑 31.7 万亿 Token（折合日消耗 1,019 万美元 API）的实时行业雷达，并直接换取超 30 万美元 OpenAI 免费内测额度与 VC 接洽。

<!-- section:claim -->
## 官方 / Theo 宣称

- 对外将 T3 Code 塑造成用爱发电的免费 MIT 开源工具，并辩称强制遥测只是为了 *"know how many users we have"*（知道有多少用户）。
- `@theo` 还在推文中宣称 DeepMind 工程师 `@PatrickToulme` 给 T3 Code 合入了 *"many PRs"*（很多 PR）。

<!-- section:evidence -->
## 源码与公开记录铁证

- **豪掷 80 万美元、彻底冷落收费老业务：** 统计 11 月 7–24 日全部 **1,151 条连续推文**，`@theo` 提及 T3 Code 高达 **162 次（14.1%）**，而对其此前主推的三款付费产品（`T3 Chat`、`UploadThing`、`ping.gg`）提及次数全部为 **0**，同时亲口证实已自掏 **80 万美元以上**打造这款免费客户端（[`2120729779511124267`](https://x.com/theo/status/2120729779511124267)）。
- **闭源遥测撑起的 31.7 万亿 Token/天 情报大屏：** 经闭源 `ingest.t3.codes` 汇聚的原始数据建起了一套实时看板，单日追踪 **31.7 万亿 Token**（11 月 18 日折合 **1,019 万美元/天** 等效 API 消费，峰值逼近 1,020 万美元/天），精确掌握各大厂份额（`99%` 订阅驱动、Codex/Claude/Antigravity 三家合计 `~98.5%`、开源权重试用从 `15%` 跌至 `6%`）。11 月 23 日有网友猜测市场份额时，`@theo` 当场嘲讽对方没权限看自己的后台数据（[`2124682906132181482`](https://x.com/theo/status/2124682906132181482)）。
- **把用户数据变现为大厂特权与资本筹码：** `@theo` 公开透露靠此在单次 GPT-6.2 Astra 评测中烧掉超 **30 万美元无上限免费 OpenAI 内测额度**（[`2122760447103484410`](https://x.com/theo/status/2122760447103484410)），参与 Google 裸机评测，并披露已有多家投资机构主动接洽（*"multiple investors have asked me about this"*，[`2123885732330885417`](https://x.com/theo/status/2123885732330885417)）。
- **夸大大厂合作记录：** 检索仓库 git 提交历史，`patrick-toulme` 实际只有 **1 个提交**（[`PR #31158`](https://github.com/pingdotgg/t3code/pull/31158)），并非所谓 *"many PRs"*。
