# #10 · 공개 `@bot` 포크 스크래핑, 경쟁자 조롱, 비판자 수익 창출 차단

> 경쟁자들이 UI 패턴을 베꼈다고 조롱하면서도, @theo는 한 개발자의 포크에 공개적으로 "Okay I'm stealing this"라고 답하고 30초 뒤 `@bot`을 투입해 그녀의 코드를 긁어갔으며, 자동 차단 봇을 운용하고 팔로워들에게 비판자들의 수익 창출을 막으라고 촉구했다.

<!-- section:claim -->
## 주장된 내용

- 11월 24일, `@theo`는 Claude Code Desktop이 사이드바 탭을 추가한 것을 공개적으로 조롱하며([`2124987957803446311`](https://x.com/theo/status/2124987957803446311)), 자신이 짝퉁 제품에 맞서 독자적인 제품 개발을 지킨다고 자처했다.

<!-- section:evidence -->
## 증거가 보여주는 것

- **30초 만의 공개 `@bot` 포크 스크래핑 (`2119240810202034645`):** 11월 8일, 독립 개발자 `@MiaAI_lab`이 직접 만든 커스텀 포크 기능을 공유하자 `@theo`는 *"Okay I'm stealing this"*라고 답했고, 30초 뒤 자신의 자동화 봇(`@bot`)을 답글에서 공개적으로 호출해 Opus 5.5로 그녀의 포크를 찾아 `beebox`에 긁어오게 했다.
- **요청 즉시 경쟁 기능 복제 (`2121017649652269120`):** 11월 13일, 한 사용자가 경쟁 도구들의 기능을 칭찬하자 `@theo`는 다시 공개 답글에서 `@bot`을 투입해 그 기능들을 T3 Code에 그대로 복제하도록 했다.
- **비판자 수익 창출 차단 및 자동 대량 차단:** X의 비판자들을 상대로 `@theo`는 팔로워들에게 커뮤니티 노트를 제출해 *"demonetize them"*하라고 권장했으며([`2120238923884696025`](https://x.com/theo/status/2120238923884696025)), 11월 24일 하루에만 약 100개 계정을 차단한 자동 X 차단 봇을 운용하고 있음을 공개적으로 확인했다([`2125077510941802509`](https://x.com/theo/status/2125077510941802509)).
