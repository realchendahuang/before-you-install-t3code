# #08 · $800,000+ का बिज़नेस लेजर और 31.7-ट्रिलियन-टोकन प्रतिदिन का कंप्यूट रडार

> डिफ़ॉल्ट रूप से चालू टेलीमेट्री कोई इंजीनियरिंग चूक नहीं थी: इसने 31.7T टोकन/दिन ($10.19M/दिन के बराबर API खर्च) वाले एक रीयल-टाइम इंटेलिजेंस रडार को फंड किया, जिसे $300k+ के मुफ़्त OpenAI अर्ली-एक्सेस टोकन और निवेशकों तक पहुँच में बदला गया।

<!-- section:claim -->
## क्या दावा किया गया था

- T3 Code को शुद्ध जुनून से बना एक मुफ़्त MIT ओपन-सोर्स टूल बताया गया, और टेलीमेट्री को केवल बुनियादी गिनती — *"know how many users we have"* — के रूप में उचित ठहराया गया।
- `@theo` ने यह भी दावा किया कि DeepMind के `@PatrickToulme` ने T3 Code में *"many PRs"* भेजे हैं।

<!-- section:evidence -->
## साक्ष्य क्या दिखाते हैं

- **$800k+ खर्च और सशुल्क उत्पादों से पूर्ण विमुखता:** 7–24 नवंबर के बीच लगातार किए गए सभी **1,151 X पोस्टों** में `@theo` ने T3 Code का ज़िक्र **162 बार (14.1%)** किया, जबकि उनके पुराने सशुल्क उत्पादों (`T3 Chat`, `UploadThing`, `ping.gg`) का ज़िक्र **0 बार** हुआ — साथ ही उन्होंने इस मुफ़्त क्लाइंट पर अपनी जेब से **$800k+** खर्च की पुष्टि सार्वजनिक रूप से की ([`2120729779511124267`](https://x.com/theo/status/2120729779511124267))।
- **31.7T-टोकन/दिन ($10.19M/दिन) एनालिटिक्स रडार:** क्लोज़्ड-सोर्स `ingest.t3.codes` के ज़रिये रखे गए रॉ इवेंट्स एक आंतरिक डैशबोर्ड को चलाते थे, जो **31.7 ट्रिलियन टोकन/दिन** (18 नवंबर को **$10.19 मिलियन/दिन** के बराबर API खर्च, जो लगभग **$10.2M/दिन** तक पहुँचा) और लैब-वार बारीक हिस्सेदारी विभाजन (`99%` सब्सक्रिप्शन-आधारित, `~98.5%` Codex/Claude/Antigravity में, ओपन-वेट हिस्सा `15%` से गिरकर `6%`) ट्रैक करता था। 23 नवंबर को जब एक कमेंटर ने बाज़ार हिस्सेदारी पर अनुमान लगाया, तो `@theo` ने उनका मज़ाक उड़ाया कि उनके पास उनके एनालिटिक्स तक पहुँच नहीं है ([`2124682906132181482`](https://x.com/theo/status/2124682906132181482))।
- **उपयोगकर्ता टेलीमेट्री को लैब सुविधाओं और VC प्रभाव में बदलना:** `@theo` ने सार्वजनिक रूप से बताया कि उन्होंने GPT-6.2 Astra बेंचमार्क पर **$300k+ के असीमित मुफ़्त OpenAI अर्ली-एक्सेस टोकन** जला दिए ([`2122760447103484410`](https://x.com/theo/status/2122760447103484410)), Google bare-metal बेंचमार्क चलाए, और निवेशकों के संपर्क संभाले (*"multiple investors have asked me about this"*, [`2123885732330885417`](https://x.com/theo/status/2123885732330885417))।
- **बढ़ा-चढ़ाकर बताया गया लैब सहयोग:** `patrick-toulme` से फ़िल्टर की गई Git commit हिस्ट्री में ठीक **1 commit** दिखता है ([`PR #31158`](https://github.com/pingdotgg/t3code/pull/31158)), *"many PRs"* नहीं।

## अपस्ट्रीम स्थिति (`ca81b7b9`)

- **सार्वजनिक रिकॉर्ड / सक्रिय बिज़नेस मॉडल:** `ingest.t3.codes` अब भी क्लोज़्ड-सोर्स और `ca81b7b9` पर डिफ़ॉल्ट रूप से सक्रिय है, और वही फ़र्स्ट-पार्टी एनालिटिक्स पाइपलाइन को डेटा देता रहता है।
