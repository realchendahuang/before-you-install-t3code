Two days after closing #40713 and #41536 while guaranteeing "zero risk" in FAQ docs, T3 Code quietly stripped both Antigravity mechanisms:

  1. **PR #43026 (2026-11-25T19:25:43Z, @juliusmarminge):** Deleted antigravityUsageLimits.ts (which polled cloudcode-pa.googleapis.com using OS keychain credentials and fake antigravity/hub headers) and removed @napi-rs/keyring from apps/server:

"Antigravity supports only ACP for external clients. Google told us that calling its internal APIs can get an account flagged."

"Either one could get users in trouble."

2. **PR #43087 (2026-11-26T15:42:39Z, @gabrielelpidio):** Removed Zed allowlist impersonation on fallback handshakes:

"On agy 1.5.0, or whenever T3 couldn't read the runtime version, the Antigravity ACP handshake sent clientInfo: { name: "zed", version: "0.0.0" }. That got agy to offer Claude and GPT models, which 1.5.0 only offers to allowlisted editors like Zed... Posing as another client breaks the same rule."

3. **v0.1.13 release notes (2026-11-26T19:32Z, 401 changes):** The 7 highlighted bullets covered GBK encoding and UI shortcuts—omitting both Google's warning and #43026/#43087 inside "Plus 380 more bug fixes and performance improvements", with 0 GitHub Security Advisories.
