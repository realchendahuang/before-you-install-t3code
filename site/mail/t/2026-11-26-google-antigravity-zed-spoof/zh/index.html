Google 警示内部 API 封号风险，v0.1.13 静默删掉冒充 Zed 握手

GitHub 部分修补 证据 #21 漏洞与封号说一套做一套

PR #43026 承认 Google 警告调用内部 API 会让账号被标记，PR #43087 撤掉 clientInfo name:"zed"，而 v0.1.13 把这两件事埋进 380 条 bug 修复里。

发件方：Julius（@jullerino）& PR #43026 / #43087 对象：Antigravity 用户（0 份安全公告） 日期：2026 年 11 月 26 日
J
Julius（@jullerino）& @gabrielelpidio<PR #43026 · PR #43087 · v0.1.13>
发送至：pingdotgg/t3code main
2026 年 11 月 25–26 日

关闭 #40713 和 #41536、并在 FAQ 文档里保证「零风险」两天后，T3 Code 悄悄拆掉了 Antigravity 的两套机制：

  1. **PR #43026（2026-11-25T19:25:43Z，@juliusmarminge）：** 删掉 antigravityUsageLimits.ts（该文件用系统钥匙串凭据、配上伪造的 antigravity/hub 请求头去轮询 cloudcode-pa.googleapis.com），并从 apps/server 移除 @napi-rs/keyring：

「Antigravity 只对外部客户端支持 ACP。Google 告诉我们，调用它的内部 API 可能让账号被标记。」

「这两件事任何一件都可能让用户惹上麻烦。」

2. **PR #43087（2026-11-26T15:42:39Z，@gabrielelpidio）：** 撤掉回退握手中冒充 Zed 白名单客户端的做法：

「在 agy 1.5.0 上，或者只要 T3 读不到运行时版本，Antigravity 的 ACP 握手就会发出 clientInfo: { name: "zed", version: "0.0.0" }。这样 agy 才会放出 Claude 和 GPT 模型——1.5.0 只对这些白名单编辑器（比如 Zed）开放……冒充别的客户端，违反的是同一条规矩。」

3. **v0.1.13 发布说明（2026-11-26T19:32Z，401 项改动）：** 7 条重点全讲 GBK 编码和 UI 快捷键——Google 的警告和 #43026/#43087 一字未提，全塞进那句「另有 380 项 bug 修复与性能改进」里，GitHub Security Advisory 挂零。
