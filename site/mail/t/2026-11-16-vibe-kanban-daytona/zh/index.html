嘲讽被投公司 Vibe Kanban，还和 Daytona 撞车

X 公开记录 证据 #06 商业与刷星霸凌与威胁

被投的 Vibe Kanban 转向 T3 Code 类似布局后关张，投资人 Theo 发文补刀嘲它的 UI——九天前他刚提议在 T3 Code 里做付费云沙箱，正撞 Daytona。

11 月 16 日，@theo 自曝曾投资并参与 Vibe Kanban，然后拿它的关张开涮：

「有趣的事实：我是 Vibe Kanban 的投资人，也给它贡献过代码。他们意识到 kanban 已经死了，开始转向基本就是 T3 Code 今天那套界面。只是没来得及做完。他们放弃了，把公司关了。这 UI 很棒……适合烧光跑道、搞死自己的生意。也许这就是科技推特这么爱它的原因 🤔」

「看在我投了 Daytona（还有你现在正生气的多数竞争对手）的份上，我真希望你这里说错了」
