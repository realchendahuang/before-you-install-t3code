41.6 GB 的假 SQLite 删除 + 每 5 秒扫一遍全机命令行

用户在 Issue #17845、#28903 和 #11222 里记录了两处本地存储与隐私缺陷：

  1. 假永久删除（#17845）： 确认弹窗承诺「永久清除该线程的对话历史」（This permanently clears conversation history for this thread），可 ThreadDeletion.ts 只是追加了一条 thread.deleted 事件 —— 3 周把 statev2.sqlite 撑到 25.9 GB，6 周涨到 41.6 GB。
  2. 每 5 秒扫全机进程（#11222 与 PR #41889）： 原生组件 t3-resource-monitor 即便诊断页已经关掉，也每 5 秒跑一次 ProcessesToUpdate::All 加 with_cmd(UpdateKind::Always)，连 440 多个不相关的应用和游戏一起扫，还带着完整命令行（里面常常躺着明文 API key 和密码）。
