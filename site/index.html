Quick mitigation playbook

While PR #42629 added DO_NOT_TRACK=1 support, DesktopShellEnvironment.ts still omits T3CODE_OTEL_SDK_DISABLED/OTEL_SDK_DISABLED and AnalyticsService.ts:156 writes a startup ID unconditionally. Combine env vars, host blocks, Managed Policy, SQLite VACUUM, and token revocation.

1. Environment opt-out (DO_NOT_TRACK=1) and OS-level hosts block

Export DO_NOT_TRACK=1 (honored via PR #42629, overriding T3CODE_TELEMETRY_ENABLED=true) alongside legacy flags in ~/.zshrc or ~/.bashrc, block ingest.t3.codes in /etc/hosts, and restart T3 Code completely.

~/.zshrc + /etc/hosts 
# Add to ~/.zshrc (or ~/.bashrc), reload shell, and restart T3 Code
export DO_NOT_TRACK=1                 # PR #42629: stops events & relay tracing (wins over T3CODE_TELEMETRY_ENABLED=true)
export T3CODE_TELEMETRY_ENABLED=false
export T3CODE_OTEL_SDK_DISABLED=true
export OTEL_SDK_DISABLED=true

# Block closed-source ingestion gateway in /etc/hosts (still required: AnalyticsService.ts:156 writes ID before check)
sudo sh -c 'printf "\n127.0.0.1 ingest.t3.codes\n::1 ingest.t3.codes\n" >> /etc/hosts'

2. Inspect statev2.sqlite bloat, run offline VACUUM, and purge Antigravity state

Even after PR #42119 added async thread-content.purge (closing #17845), source threads with live forks/merge-backs/subagents and tombstones remain, and reclaiming disk space requires an offline VACUUM. Quit T3 Code first.

SQLite Audit, VACUUM & Cleanup

1. Persistent user/system env vars (DO_NOT_TRACK=1) and Windows hosts block

PR #42629 forwards DO_NOT_TRACK=1 through Windows profiles and backend configuration, while DesktopShellEnvironment.ts still omits OTEL_SDK_DISABLED. Set all flags, block ingest.t3.codes, and reboot or restart background services.

PowerShell (Run as Administrator) 
# Set User & Machine telemetry opt-out variables (including DO_NOT_TRACK=1 from PR #42629)
@("User", "Machine") | ForEach-Object {
  [Environment]::SetEnvironmentVariable("DO_NOT_TRACK", "1", $_)
  [Environment]::SetEnvironmentVariable("T3CODE_TELEMETRY_ENABLED", "false", $_)
  [Environment]::SetEnvironmentVariable("T3CODE_OTEL_SDK_DISABLED", "true", $_)
  [Environment]::SetEnvironmentVariable("OTEL_SDK_DISABLED", "true", $_)
}

# Block ingest.t3.codes in C:\Windows\System32\drivers\etc\hosts
$hosts = "$env:SystemRoot\System32\drivers\etc\hosts"
Add-Content -Path $hosts -Value "`r`n127.0.0.1 ingest.t3.codes`r`n::1 ingest.t3.codes"
