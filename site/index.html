Quick Mitigation Playbook

While PR #42629 added DO_NOT_TRACK=1 support, DesktopShellEnvironment.ts still omits T3CODE_OTEL_SDK_DISABLED/OTEL_SDK_DISABLED and AnalyticsService.ts:156 still writes a startup ID unconditionally. Combine env vars, host blocks, Managed Policy, SQLite VACUUM, and token revocation.

1. Environment Opt-Out (DO_NOT_TRACK=1) + OS-Level Hosts Block (macOS / Linux)

Export DO_NOT_TRACK=1 (honored via PR #42629, overrides T3CODE_TELEMETRY_ENABLED=true) alongside legacy flags in ~/.zshrc or ~/.bashrc, block ingest.t3.codes in /etc/hosts, and restart T3 Code completely.

~/.zshrc + /etc/hosts 
# Add to ~/.zshrc (or ~/.bashrc), reload shell, and restart T3 Code
export DO_NOT_TRACK=1                 # PR #42629 (v0.1.12): stops events & relay tracing (wins over T3CODE_TELEMETRY_ENABLED=true)
export T3CODE_TELEMETRY_ENABLED=false
export T3CODE_OTEL_SDK_DISABLED=true
export OTEL_SDK_DISABLED=true

# macOS GUI launch race mitigation (ensures Finder/Dock launches inherit flags before shell discovery)
launchctl setenv DO_NOT_TRACK 1
launchctl setenv T3CODE_TELEMETRY_ENABLED false

# Block closed-source ingestion gateway + build-injected Axiom OTLP relay host in /etc/hosts
# (Do NOT block daily-cloudcode-pa.googleapis.com: official Google agy CLI depends on it)
sudo sh -c 'printf "\n127.0.0.1 ingest.t3.codes\n::1 ingest.t3.codes\n127.0.0.1 us-east-1.aws.edge.axiom.co\n::1 us-east-1.aws.edge.axiom.co\n" >> /etc/hosts'

2. Inspect statev2.sqlite Bloat, Run Offline VACUUM & Purge Antigravity State

PR #42119 shipped in v0.1.12 (adding async thread-content.purge). On v0.1.11 or earlier, running VACUUM; alone deletes zero soft-deleted messages or FTS5 indexes—upgrade first or purge deleted_at IS NOT NULL rows offline before compacting. Quit T3 Code first.

SQLite Audit, VACUUM & Cleanup 
# Inspect local SQLite database size and retained deleted-thread markers

1. Persistent User/System Env Vars (DO_NOT_TRACK=1) + Windows Hosts Block

PR #42629 forwards DO_NOT_TRACK=1 through Windows profiles and backend configuration, while DesktopShellEnvironment.ts still omits OTEL_SDK_DISABLED. Set all flags, block ingest.t3.codes, and reboot/restart background processes.

PowerShell (Run as Administrator) 
# Set User & Machine telemetry opt-out variables (including DO_NOT_TRACK=1 from PR #42629)
@("User", "Machine") | ForEach-Object {
  [Environment]::SetEnvironmentVariable("DO_NOT_TRACK", "1", $_)
  [Environment]::SetEnvironmentVariable("T3CODE_TELEMETRY_ENABLED", "false", $_)
  [Environment]::SetEnvironmentVariable("T3CODE_OTEL_SDK_DISABLED", "true", $_)
  [Environment]::SetEnvironmentVariable("OTEL_SDK_DISABLED", "true", $_)
}

# Block ingest.t3.codes + build-injected Axiom OTLP relay host in C:\Windows\System32\drivers\etc\hosts
# (Do NOT block daily-cloudcode-pa.googleapis.com: official Google agy CLI depends on it)
$hosts = "$env:SystemRoot\System32\drivers\etc\hosts"
Add-Content -Path $hosts -Value "`r`n127.0.0.1 ingest.t3.codes`r`n::1 ingest.t3.codes`r`n127.0.0.1 us-east-1.aws.edge.axiom.co`r`n::1 us-east-1.aws.edge.axiom.co"
